## Demo purpose
Governed autonomy: the 60-second field, the no-code approval rule, and the governance that makes IT sleep.

## Best personas
CIO, CTO, key users, admins

## Prerequisites
- Enterprise database
- a staging-flavoured framing ('never on production live')
- one prepared customisation scenario

## Minimum demo data
- A form to extend
- an approval-rule scenario on a real action
- the export screen reachable

## Recommended flow
- Add a field to a form in 60 seconds
- tailor the view
- add an approval rule on the confirm button, second user approves
- show Studio export (the governance artifact)

## Wow moments
